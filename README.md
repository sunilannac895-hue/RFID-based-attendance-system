RFID-Based Attendance System

## 📌 Project Overview
The RFID-Based Attendance System is an automated attendance monitoring system using RFID technology and Arduino Uno. It identifies students using RFID cards and records their attendance.

## 🎯 Objectives
- Automate the attendance process.
- Reduce manual attendance work.
- Identify students using unique RFID cards.
- Make attendance recording faster and easier.

## 🛠️ Components Used
- Arduino Uno
- RFID Reader (RC522)
- RFID Cards/Tags
- LCD Display
- Buzzer
- Connecting Wires
- Breadboard
- USB Cable

## ⚙️ Working Principle
1. The RFID reader scans the RFID card/tag.
2. Arduino Uno reads the unique RFID ID.
3. The ID is compared with the registered student IDs.
4. If the ID is valid, attendance is recorded.
5. The system displays the attendance status.

## 💻 Software Used
- Arduino IDE
- Embedded C / Arduino Programming

## ✨ Features
- RFID-based student identification
- Automatic attendance recording
- Fast and simple operation
- Reduces manual errors
- Low-cost hardware implementation
